一、 企劃情報與背景分析[cite: 3]

消費者痛點：解決藝文受眾資訊碎片化、觀展計畫難以落實為實際行程的問題[cite: 3]。貼文存了常忘記去，手動將展覽地點與時間貼進行事曆十分不便，且綜合型平台多包含付費活動，不適合隨性免費觀展的需求[cite: 3]。

產業情報與競爭者：

  • 綜合型售票平台 (Accupass、KKTIX)：資訊齊全但偏向交易，無法專攻免費展覽[cite: 3]。
  • 社群平台 (IG、FB)：資訊多元但缺乏時間排程，且不一定是當期活動[cite: 3]。
  • 快閃店與體驗經濟崛起，從「單向靜態觀賞」轉向「微型體驗與主動參與」[cite: 4]。

二、 現況分析與策略目標 (SWOT)[cite: 5, 6]

內部優勢 (Strengths)[cite: 5] 內部劣勢 (Weaknesses)[cite: 5]
  • 資訊整合度高，解決資訊分散痛點[cite: 5]。
  • 使用者介面體驗佳 (地圖定位/分類搜尋)[cite: 5]。
  • 支援用戶收藏功能[cite: 5]。
  • 初期品牌知名度低，用戶流量不足[cite: 5]。
  • 缺少主辦方、品牌方直接合作管道[cite: 5]。
  • 營運資金有限[cite: 5]。
外部機會 (Opportunities)[cite: 5] 外部威脅 (Threats)[cite: 5]
  • 快閃店、音樂節近年蓬勃發展[cite: 5]。
  • 年輕族群熱衷打卡、探索活動[cite: 5]。
  • 主辦方急需曝光的宣傳管道[cite: 5]。
  • 很多社群品牌已有大量的推薦文[cite: 5]。
  • 大型售票平台可能跨足相關業務[cite: 5]。
  • 活動資訊即時性低可能導致用戶體驗不佳[cite: 5]。

關鍵解決對策 (明確角色分工)[cite: 5, 6, 9]

1. KOL / 社群特派員 (負責宣傳推廣)：
與大專院校社團及風格創作者合作，專職負責話題行銷。透過發布短影音並每週進行全台開箱與私房景點推薦，快速擴大平台知名度與曝光[cite: 6, 9, 10]。
2. 一般民眾 (即時回報機制)：
建立遊戲化社群，一般用戶只要在現場掃 QR Code 打卡、回報即時人潮與排隊狀況，即可獲得點數獎勵參與抽獎。這能確保資訊的準確度與即時性，並以遊戲化方式降低平台維護成本[cite: 5, 6]。
3. AI 輔助監測 (補足資訊量)：
設定 AI 系統自動監測全台各大展覽館與市集主辦方的粉專及關鍵字，第一時間抓取最新消息並上架平台，確保平台初期資訊豐富度[cite: 6]。
4. 主辦方合作方案：
初期推出「免費自助上架及基礎推播」方案，吸引品牌主辦方主動進駐，解決初期缺乏合作管道的劣勢[cite: 5, 9]。

三、 STP 市場策略設計[cite: 7, 8]

市場區隔 (Segmentation)[cite: 7]

  • 區隔 A (尋找熱門體驗)：18-25歲大學生及年輕族群，善用社群軟體，喜愛打卡拍照[cite: 7]。
  • 區隔 B (隨性打發時間)：20-40歲都會區通勤族、自由工作者等文青族群[cite: 7]。
  • 區隔 C (提前規劃行程)：25-40歲上班族、情侶及朋友出遊族群[cite: 7]。

目標市場 (Targeting)[cite: 7]

  • 主要目標：區隔年輕潮流族群。藉由他們熱衷打卡與上傳照片，快速累積平台初期的真實內容與聲量[cite: 7]。
  • 次要目標：隨性漫遊族群能最大化「周邊地圖」使用率；提前規劃族群則能透過「愛心收藏」與「行事曆」提升平台留存率[cite: 7]。

市場定位聲明 (Positioning)[cite: 8]

「展」開生活為熱愛探索活動、卻常錯過展期的年輕潮流族群，提供快閃店與展覽的一站式探索服務，整合周邊活動搜尋、免費展覽篩選、地圖導航、行事曆匯入及掃碼集點兌禮功能，讓使用者輕鬆掌握展覽資訊，不再錯過精彩活動[cite: 8]。

四、 行銷戰術設計 (7Ps)[cite: 9]

  • 產品 (Product)：消費者端包含一鍵同步行事曆、遊戲化集點打卡系統、按愛心收藏功能；主辦方端提供免費自助上架與後台數據分析[cite: 9]。
  • 價格 (Price)：消費者完全免費；主辦方初期免費上架推播，中後期提供精準推播專案、首頁廣告置頂等加值服務[cite: 9]。
  • 通路 (Place)：線上雙平台 (Google Play / App Store) 與社群主頁導流；線下於合作展覽館與快閃店設置下載立牌[cite: 9]。
  • 宣傳 (Promotion)：透過社群特派員(創作者/社團)進行短影音話題擴散；現場設置QR Code鼓勵民眾掃碼打卡賺點數抽獎[cite: 9, 10]。
  • 人員 (People)：社群操作人員制定資訊收集 SOP；客服小編建立即時 FAQ 與 24 小時負面評價應變處置流程[cite: 9]。
  • 有形展示 (Physical Evidence)：質感數位徽章/卡片；實體立牌、地貼與文宣；主辦方官方認證標籤[cite: 9]。
  • 流程 (Process)：消費者從搜尋、收藏/匯入到現場掃碼集點抽獎的完整體驗；主辦方註冊、上架、審核至查看數據的流程[cite: 9]。
